# 切削工具メーカー Webサイト「ノクサスツール」

## 概要

SHINBIデザインスクールの卒業制作として、架空の切削工具メーカー「株式会社ノクサスツール」のWebサイトを個人で制作しました。

以前、機械加工の業務に携わっていた経験を生かし、NC旋盤向けの旋削チップ・ホルダーを中心とした企業・製品サイトとして企画しました。

サイトの企画、ターゲット設定、Figmaによるデザインカンプ制作、架空製品・コンテンツの設定、製品画像などの素材制作、HTML・CSS・JavaScriptによるコーディング、公開まで一人で担当しています。

## 制作期間

2025年12月上旬 ～ 2026年1月末（約2か月）

## 制作形態

個人制作（卒業制作）

## 制作目的・コンセプト

卒業制作のテーマを決める際、「誰が、どのような目的で利用するWebサイトなのか」を設定することを重視しました。

前職では機械加工に携わり、実際に切削工具や工具メーカーのカタログからチップ・ホルダーを探す機会がありました。その経験を生かし、機械加工の現場で工具を選定・使用する人を主な利用者として想定した切削工具メーカーのWebサイトを企画しました。

単に工具メーカーらしい外観を再現するだけではなく、自身が加工現場で工具を探していた経験から、「製品を探しやすく、選択した製品についてそのまま問い合わせまで進めるサイト」を意識して構成しています。

制作範囲では旋削加工用のチップ・ホルダーを中心に、製品情報、ニュース、会社概要、お問い合わせなど、切削工具メーカーのWebサイトとして必要となるコンテンツを想定して制作しました。

## ターゲット

主に以下のような利用者を想定しています。

-   NC旋盤などを使用する機械加工の現場担当者
-   加工内容に適したチップ・ホルダーを探している人
-   製品情報を確認したうえで見積もりや問い合わせを行いたい人

## 主な実装内容

### 製品検索・絞り込み

製品一覧から目的の製品を探しやすくするため、JavaScriptを使用した検索・絞り込み機能を実装しました。

キーワードに加え、サイズ・角度・材質・用途などの条件から製品を絞り込めるようにし、検索結果に応じて表示件数も更新されるようにしています。

### 製品選択から問い合わせへの情報引き継ぎ

前職で実際に工具メーカーのカタログからチップやホルダーを探していた経験をもとに、「製品を探す」だけで終わらず、そのまま問い合わせまで進める導線を考えました。

製品一覧から対象製品を選択すると問い合わせページへ移動し、型番・サイズ・角度・材質・用途などの製品情報が問い合わせ内容へ引き継がれるようJavaScriptで実装しています。

「製品を探す → 製品を選択する →
問い合わせる」という一連の流れを、できるだけ少ない操作で行えることを意識しました。

### UI・アニメーション

静的なレイアウトだけでなく、JavaScriptを使用してサイトの操作感を高めるUIやアニメーションも実装しました。

主な実装内容は以下のとおりです。

-   ハンバーガーメニュー
-   スクロールに応じた要素の表示アニメーション
-   パララックス表現
-   カードのホバー演出
-   スムーズスクロール
-   スクロール進捗表示
-   ページ読み込み時のアニメーション

## 製品・画像制作

切削工具メーカーの製品サイトとして成立させるため、掲載するチップ・ホルダーの製品画像も多数用意しました。

製品画像の制作にはImageFXやGeminiなどの画像生成ツールを活用しています。

単に異なる画像を並べるのではなく、実際の切削工具を参考にしながら、チップ形状やチップブレーカーなどの違いも意識して架空製品を設定しました。

架空の製品であっても、切削工具を扱った経験のある人が見た際に不自然になりすぎないよう、実際の工具の構造や用途を意識して素材を制作しました。

## 制作時に工夫した点

### 実体験をサイト設計に反映

機械加工の現場で実際に工具を使用し、カタログから製品を探した経験をサイト設計に反映しました。

特に、製品一覧から対象製品を選択し、その製品情報を保持したまま問い合わせへ進める機能は、実際に工具を探す側だった経験から考えたものです。

見た目だけを工具メーカー風にするのではなく、実際の利用場面を想定した機能と導線を取り入れることを意識しました。

### 製品点数と素材の制作

工具メーカーのWebサイトらしい製品一覧を作るためには、ある程度の製品数と、それぞれに対応する画像が必要でした。

そのため、チップやホルダーの画像を多数制作し、製品ごとの差異を持たせながら、サイト全体として統一感が大きく崩れないよう調整しました。

特にチップについては、形状だけでなくチップブレーカーなど実際の工具に存在する要素も考えながら製品を設定しました。

### Web制作と機械加工の知識を組み合わせる

自身が経験してきた機械加工と、Webデザイン・コーディングの学習内容を組み合わせることも本制作のテーマの一つです。

サイトの題材だけを製造業にするのではなく、製品分類や工具の見せ方、利用者が製品を探して問い合わせるまでの流れなど、加工現場での経験をWebサイトの内容や機能へ反映しました。

## 制作補助・作業効率化

製品画像を多数扱う必要があったため、画像の背景透過やファイル名変更などの単純作業を効率化する目的で、Pythonを使用した一括処理用の簡易スクリプトも作成しました。

これらは授業課題ではなく、制作中に必要性を感じて個人的に作成したものです。
